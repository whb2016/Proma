# Proma v0.17.102 更新

Pioneer fork 的第二个 Windows 版本。基线仍为上游已发布的 v0.17.1，本次为 fork 自有改动。

## 新功能

- **微信支持接收 Agent 发来的图片和文件** — 此前微信 Bridge 只能给用户发文本。现在 Agent 可以主动把图片或文件发给你：图片（png/jpg/jpeg/gif/webp/bmp）以图片形式发送，其余按文件发送，单个上限 20MB。可发送范围与 Agent 自身的文件读取范围一致（会话工作台、已授权的附加目录、项目文件根），无需先把文件复制到工作目录。若要发送这些范围之外的文件（例如系统图片目录），把该目录加入会话或工作区的附加目录即可。
- **Agent 请求携带用户标识** — 向 Anthropic 及其协议兼容端点发起的 Agent 请求会带上 `metadata.user_id`，便于上游按用户维度做用量统计与限流。该标识由通用设置里的用户名哈希得到，不含任何可识别个人信息，用户名为中文也不影响。

## 变更

- **微信协议版本对齐官方** — iLink 请求统一携带 `channel_version: 2.0.0`，此前部分接口未携带版本号。

## 已知事项

- Windows 安装包未做代码签名，安装时可能出现 SmartScreen 提示。
- 仅提供 Windows x64 构建。
