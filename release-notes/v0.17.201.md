# Proma v0.17.201 更新

本版把上游 `proma-ai/Proma` 的 v0.17.15 合了进来（18 个提交，84 个文件），fork 自有功能（微信 / QQ 远程连接、定时任务推送渠道、更新源指向本 fork 等）全部保留。基线从上游 0.17.1 换到 0.17.15，版本号相应从 `0.17.1xx` 进到 `0.17.2xx`。

## 新功能

以下均来自上游：

- **应用内浏览器自动化** — Agent 可以在受管的应用内浏览器里导航、点击、填表、执行脚本和截图，浏览器面板能并排看着它操作。配套的 `in-app-browser` 技能会在首次启动时自动装上。
- **Skill 使用记录** — 每一轮对话会汇总本轮实际用到的 Skill，可展开查看详情。
- **历史消息选区引用** — 在历史消息里选中一段文字可以作为 chip 引到输入框；正文里的 chip 点一下能跳回原处并高亮。
- **HTML 文件默认走预览渲染**，不再只显示源码。
- **Agent 会话记住当前活动的 worktree**，重开不用再选一次。
- 侧栏会话列表的可读性改善。

## 变更

- **设备迁移改为引导式流程** — 上游移除了内置的迁移打包与导入弹窗，以及 `.proma-backup` / `.proma-share` 文件关联；设置里的「数据迁移」页现在给出两段提示词（创建压缩包 / 恢复数据），由 Agent 压缩 `.proma` 文件夹并在新设备上解压、重新分配项目路径、重建索引。

## Bug 修复

以下均来自上游：

- 修复 Windows 下 Tab 栏操作区的位置。
- 修复切换 Tab 后草稿的滚动位置丢失。
- 修复不支持的文件类型预览时崩溃。
- `git diff` 现在会统计未跟踪文件的行数；Agent 生成的文件改动能正常显示。
- MCP over HTTP 的会话过期后自动恢复。
- 修复多仓库目录下的 worktree 选择器。
- 停止 / 恢复的竞态下不再出现重复的用户消息气泡。
- 目录项在扫描过程中消失不再报错。
- 应用内浏览器的标签页处理与导航若干修复。
