# Proma v0.17.201 更新

本版本是 Pioneer fork 的首个 Windows 构建，基线为上游 Proma v0.17.2（Agent 运行时已全面迁移至 Pi-only）。以下只列出相对该基线的差异，上游功能与更新日志请参见上游项目。

## 变更

- **移除设置中的「Proma 教程」入口** — 设置面板左侧导航不再显示该项。教程功能本身保留：主区教程 Tab、新手引导完成后自动打开教程的行为均未改动。
- **修复资源拷贝在 Windows 上静默失败** — 构建脚本原先用 `cp -r` 并抑制错误，而 Bun Shell 的内置 `cp` 不接受 `-r`，导致 `dist/resources` 缺失，表现为应用图标、托盘图标与原生启动页加载失败。改为跨平台脚本并去掉错误抑制，拷贝失败会中断构建而非静默通过。
- **更新源指向本 fork** — 自动更新、更新日志与「去下载」入口均改为读取本 fork 的 Release，不再指向上游仓库。设置中的「项目地址」仍指向上游项目主页。

## 已知事项

- Windows 安装包未做代码签名，安装时可能出现 SmartScreen 提示。
- 仅提供 Windows x64 构建。
