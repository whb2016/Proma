# Proma v0.17.408 更新

## 变更

- Chat 模式启用提示词缓存（prompt caching）：多轮对话中重复发送的前缀（系统提示词、工具定义、历史消息）按缓存价计费，读取约为原价的十分之一。实测一段十轮左右的长对话可省约一半的输入费用，轮数越多越明显。仅对 Anthropic 原生渠道与 Anthropic 兼容渠道生效；其余兼容渠道（DeepSeek、智谱、Kimi、通义等）由服务端自动做前缀缓存，不需要客户端参与。
- 若「设置 → 提示词管理 → 追加日期时间和用户名」处于开启状态，系统提示词末尾的时间戳精确到分钟，会让缓存每分钟失效一次。**关掉这个开关，缓存才能在多轮追问之间持续复用。**
- Chat 的模型请求也带上 `metadata.user_id`，与 Agent 模式共用同一套构造（通用设置里的用户名哈希 + 会话标识），便于上游按用户维度做用量统计与限流。该标识不含任何可识别个人信息。
