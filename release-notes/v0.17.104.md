# Proma v0.17.104 更新

Pioneer fork 的第四个 Windows 版本。基线仍为上游已发布的 v0.17.1，本次为 fork 自有改动。

## 新功能

- **定时任务的完成通知可以推到远程渠道了** — 任务每次跑完都会弹一条本机系统通知（点击直接打开那次运行的子会话，受设置里的通知总开关约束）；此外还能在任务表单里挑**一个已连接的聊天**把结果一并推过去，飞书、微信、QQ 都支持，可单独设成功 / 失败 / 都通知。此前只能推飞书。

  **Agent 建任务时默认推回消息来源的那个渠道** —— 在微信里让 Agent 建的任务，结果就发回那个微信会话；在 QQ 群里建的发回那个群；桌面端建的则只有本机通知。对话里说「别往群里发了」也能改。

  两点平台限制：QQ 的完成通知走**主动消息**，用户若在 QQ 里关掉「允许主动发送」则一律失败；微信的推送依赖收消息时下发的会话上下文，官方未说明其有效期，长期未互动的会话有可能推送失败 —— 两种情况都会另发一条本机通知说明原因，不会静默丢结果。**钉钉暂不支持**：它只有收消息时下发的临时回复地址（约 1.5 小时过期），到点推送必然已失效。

## 变更

- **去掉商业版推广** — 模型配置列表第一项的「Proma 商业版」卡片、以及填写第三方中转站地址时风险提示里的推广段落都已移除。中转站本身的风险告警保留。
