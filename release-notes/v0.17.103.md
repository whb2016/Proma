# Proma v0.17.103 更新

Pioneer fork 的第三个 Windows 版本。基线仍为上游已发布的 v0.17.1，本次为 fork 自有改动。

## 新功能

- **远程连接支持 QQ 机器人** — 设置-远程连接新增 QQ，与钉钉一样可配置多个 Bot，每个 Bot 独立凭证与默认项目。只需填入 QQ 开放平台的 AppID 与 AppSecret，走 WebSocket 长连接，不需要公网地址或端口映射。支持群里 @ 机器人与单聊，双向都支持图片和文件：你发的图片/文件会存入会话附件目录交给 Agent，Agent 也可以主动把产物发回来（单个上限 10MB）。回复以 markdown 发送。

  两点平台限制需要留意：**事件订阅权限（GROUP_AND_C2C_EVENT）要在 QQ 开放平台单独申请**，缺权限的表现是连上后立刻断线；QQ 对被动回复有条数硬配额（群聊 5 分钟内 5 条、单聊 60 分钟内 4 条），超长回复会截断并在末尾提示剩余字数。

## 变更

- **微信与 QQ 单聊不再回复「⏳ Agent 处理中...」** — 改为点亮 IM 原生的「正在输入」状态：少一条噪音消息，也不会在会话里留下一条过时的中间态文本。QQ 群聊不支持该状态，改为静默等待。
- **微信协议头对齐官方文档** — `X-WECHAT-UIN` 改为每次请求重新生成，此前整个会话复用同一个值。属规范对齐，改动前无可见症状。
