# Proma v0.17.501 更新

合入上游 v0.17.42（75 个提交），本 fork 自有功能无改动。这一版的重心是 Agent 的稳定性与流畅度。

## 新功能

- **Agent 运行时搬到独立进程** —— Pi runtime 不再跑在应用主进程里，而是各会话自己的独立进程（任务管理器里显示为 `Proma Runtime`）。好处是 Agent 干重活时不再拖慢界面，运行时崩溃也不会带走整个应用。同时应用恢复了后台节流，最小化时更省电。
- **待办页支持视图筛选** —— 全部 / 今天 / 未来一周 / 已完成 / 按分组，刚勾掉的事项会短暂停留在列表里而不是立刻消失。
- **新增「提示词澄清」内置 Skill** —— 需求描述得含糊时，Agent 会先反问把要求问清楚，再动手。
- 模型渠道预置里加上 **GLM-5.3**（含只有开关、没有思考档位的正确处理）与**豆包 Seed 2.1 Pro / Turbo**。
- **受管浏览器可以手动关掉了**，也放开了内网地址访问与页面下载。

## 变更

- **长会话不再越跑越慢** —— 修掉了一处随消息数累积的性能退化，几十轮之后的响应速度与刚开始基本一致。
- **流式输出更平滑** —— 改用 Pi 原生的增量事件，去掉了每帧重新解析整篇 Markdown 的开销；侧边栏归档会话改为懒加载，会话切换、标签切换、用量刷新都不再引起输入框重绘。
- 流式过程中的历史步骤会逐步折叠，长任务不再刷满屏幕。
- 一次性补回预置模型时会记录已应用的更新，不再把你手动删掉的候选模型反复加回来。

## Bug 修复

- 修复 Agent 提问（AskUserQuestion）时不等你回答就继续往下跑。
- 修复排队消息的一批问题：后台标签页里重复入队、排队状态在切换会话后丢失、排队中的运行状态显示错误。
- 修复会话标题自动重命名失败（自定义渠道下会回退到兜底命名）。
- 修复会话级文件面板显示的不是当前会话的文件。
- 修复渲染进程异常后无法自动恢复。
- 修复语音输入重启后生命周期未重置导致采集不可用。
- 修复思考块闪烁、空思考块提前渲染、流式过程中模型名与消息头消失。
- 修复工具调用展示的一批问题：控件与描述错位、重复的工具标签。
- 修复切换会话时受管浏览器残留上一个会话的画面、浏览器面板动画卡顿。
- 修复历史消息引用浮层位置漂移、编辑器更新时输入焦点丢失。
- 修复侧边栏固定图标不可见、提示浮层不自动消失。
