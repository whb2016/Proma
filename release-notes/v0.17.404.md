# Proma v0.17.404 更新

## 新功能

- **顶部标签栏新增常驻「翻译」入口**（在「草稿」左边，和草稿一样关不掉）。左边输原文，点「翻译」，右边流式出译文并按 Markdown 渲染；原文与译文框的右上角各有一个复制按钮。
  - 目标语言支持中文、英文、日语（带国旗图标），默认中文。模型单独选，不影响 Chat 里的选择。
  - 齿轮进设置：翻译提示词可自由编辑（保存 / 重置为默认），以及「开启思考」开关（默认关闭，思考过程不展示）。
  - 提示词硬性要求保持原文的分段与换行结构，也保留标题、列表、代码块等 Markdown 标记。改提示词时 `{{targetLanguage}}` 会被替换成当前目标语言；把这个占位符删掉也不会失效，目标语言会自动补在末尾。
  - 翻译不产生会话、不落盘。翻译进行中按钮变「停止」，可随时中止；中途切到草稿或其他会话再切回来，流式输出仍在继续。

## 变更

- **关闭内置的受管浏览器与内置 Chrome DevTools MCP**。本机日常是文档处理、脚本开发、信息获取和定时任务，网页自动化改用外部 playwright-cli（真 Chrome、独立持久登录态、可直接对单个元素截图落盘）。
  - Agent 不再有 14 个 `Browser*` 工具，系统提示词里对应的一节也一并去掉（否则只会教模型去调用已经不存在的工具）；每次请求的提示词相应变短。
  - 能力列表里不再出现内置的「Chrome 浏览器」项（它的注入器其实早已失效，开关是空的）。同名保留键一并释放，工作区 `mcp.json` 现在可以自己配 `chrome-devtools`。
  - 内置的 `in-app-browser` Skill 已退役，老工作区里装过的那份会在启动时自动清掉。
  - 浏览器面板本身保留，仍可手动浏览网页；只是 Agent 不再有对应工具。

## Bug 修复

- 修复退役的内置 Skill 每次启动被「删掉又拷回来」，导致新建工作区仍会装上已退役的 Skill。
