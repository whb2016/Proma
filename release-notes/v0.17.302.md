# Proma v0.17.302 更新

## 新功能

- **定时任务可以把图片和文件发给你了** —— 任务配了微信或 QQ 通知渠道时，Agent 在运行中可以调用「发送附件」工具，把截图、报表等产物直接发到那个聊天：图片按图片发送，其余按文件发送（微信上限 20MB，QQ 上限 10MB）。此前完成通知只带文字摘要，Agent 产出的图片没有任何送达途径。可发送范围与 Agent 自己的文件读取范围一致，仍然限制在会话工作台、已授权目录与项目文件根之内。

## 变更

- **没有外发渠道的定时任务不再谎称「已发送」** —— 桌面端任务（以及渠道选了飞书的任务）现在会被明确告知它没有把文件交给用户的通道，要求给出产物的绝对路径。此前 Agent 会把「读取了图片文件」当成「已经发给用户」，回复里出现并不存在的「如上图」。
- 飞书渠道暂不支持发送附件（缺出站图片上传能力），与在飞书聊天里直接对话时的行为一致。
