# Proma v0.17.405 更新

## Bug 修复

- 修复翻译页译文不换行：原文分了行，译文却糊成一大段，且换任何模型都一样。原因在渲染层不在模型 —— Markdown 里单个换行不算换行、会被合并进同一段落，而译文此前用的是普通 Markdown 渲染，把模型如实输出的换行吃掉了（模型偶尔多打一个空行，那一处才会断开，所以看着像模型时好时坏）。现在译文改用与用户消息相同的换行保留规则，逐行对应显示；代码块内部不受影响。
  - 如果你之前为了绕过这个问题，在翻译设置里改过提示词（比如要求「每行之间留一个空行」），装上这一版后请点「重置」换回默认提示词，否则译文会变成双倍行距。
