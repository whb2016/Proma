# Proma v0.17.401 更新

合入上游 v0.17.26（37 个提交），本 fork 自有功能无改动。

## 新功能

- **Windows 的 Agent 状态通知与托盘悬停面板** —— Agent 从「运行中」转为「需要交互」或「已完成」时（以及出错需要注意时）弹系统通知并可选提示音；鼠标悬停托盘图标会浮出正在跑的会话列表，点一条直接跳到那个会话。此前这套「灵动岛」只有 macOS 有，Windows 只能自己盯着窗口。
- **定时任务支持时间窗口与星期限制** —— 间隔型任务新增「每天只在某个时间段内跑」（如 10:00–22:00）和「只在某些星期跑」（如工作日）两个维度，一条任务就能表达「工作日 10 点到 22 点每 20 分钟检查一次」，不用再拆成几十条。日历视图会把这些活跃窗口画出来。
- **受管浏览器支持真实弹窗与下载** —— `window.open()` 的 OAuth 中转页、页面内生成的预览能正常弹出；点击下载会静默保存到系统「下载」目录（文件名做过清理，下载地址仍走公网/loopback 校验与 DNS 防护，非受管来源的下载一律拒绝）。
- **搜索改为按模式隔离的模糊匹配**，结果排序与展示一并优化。
- 模型渠道预置里加上 **Qwen3.7 Flash**。

## 变更

- **界面更跟手** —— 输入框与历史消息的渲染彻底拆开，后台会话的流式输出不再引起前台重绘，历史选区引用改为引用式比较，去掉了滚动时的全量扫描。多个会话同时跑长任务时输入卡顿会明显改善。
- 排队中的消息不再弹 toast，改为在后台派发；同一会话里之前排队的运行会被折叠起来。
- 压缩前的过程消息会折叠，不再占满屏幕。
- 定时任务的调度字段改动会做归一化与合法性校验：切换调度类型时自动清掉旧模式不适用的字段，`maxRuns` 传 null 明确表示不限次。
- Agent 回复里的链接改为在受管浏览器中打开。
- 孤儿数据清理默认关闭。

## Bug 修复

- 修复 Windows 上 `Ctrl+B` 与系统/编辑器快捷键冲突。
- 修复语音输入三处问题：授予麦克风权限后采集中断、重启后采集未就绪、听写就绪状态早于实际可采集。
- 修复受管浏览器的过期标签导航事件被误处理，以及方向键不带键码导致页面不滚动。
- 修复富文本编辑时 Mermaid 预览丢失，以及标签式加粗标记渲染错误。
- 修复展开态灵动岛在空闲模式下没有收起/关闭入口。
- 修复 OpenCode Go 的 Vision Relay 模型路由。
- 修复切换 Skill 启用状态时列表顺序跳动、Skill 调用 chip 高度不齐、浏览器文件面板收起时多余的 toast。
- 修复输入焦点被抢占与草稿输入延迟。
