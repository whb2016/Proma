# Proma v0.17.301 更新

合入上游 v0.17.16（7 个提交），本 fork 自有功能无改动。

## 变更

- **侧边栏长列表改为虚拟滚动** — 会话数量多时侧边栏只渲染可见区域；输入框、滚动缩略图、置顶用户消息一并做了重渲染优化，流式输出时不再按 token 触发侧边栏重绘。
- **受管浏览器允许访问本机 loopback** — `localhost` / `127.0.0.1` / `::1` 可以打开了（默认按 http 而非 https 处理），方便让 Agent 预览本地开发服务；局域网与其他私网地址仍然禁止。
- **网络搜索不够用时回落到浏览器** — 内置 in-app-browser Skill 放宽了选择规则：`WebSearch` 不可用、结果为空或质量／时效性不足时，Agent 可以改用浏览器继续检索核验。

## Bug 修复

- 修复 Windows 上受管浏览器的关闭按钮压住窗口控件（最小化/最大化/关闭）。
- 修复多个 Agent 会话共用浏览器原生视图导致的串台。
- 浏览器截图返回非法图片内容时不再直接塞给模型。
- 修复 macOS 灵动岛已查看后错误状态提示不消失。
