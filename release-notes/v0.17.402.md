# Proma v0.17.402 更新

## 新功能

- **「每天定点」支持只在某些星期运行** —— 定时任务选「每天定点」后多了一个「运行日」下拉（每天 / 工作日 / 周末 / 自定义），所以「周一至周五 22:30」现在是两个下拉的事。此前这个组合只能绕一圈实现：「每周定点」只支持选**一个**星期几，而「每隔一段时间」得配一个 1 分钟宽的时间窗口才能压成固定时刻。
  - 日历视图与任务列表都会跟着只显示实际运行的那些天，标签也从「每天 22:30」变成「工作日 22:30」。
  - Agent 建任务时同样可用（`daily` + `activeWeekdays`），内置 automation Skill 已更新说明。
  - 「每日执行窗口」仍然只属于「每隔一段时间」——「每天定点」本身就是一个固定时刻，不需要窗口。
